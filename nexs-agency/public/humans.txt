/* NOT CLAIMED */
  This file previously asserted several things that were not true, which is
  worse than saying nothing. For the record:
  - No service worker is registered, so this is not a Progressive Web App.
    The web app manifest exists; a manifest alone is not a PWA.
  - WCAG 2.1 AA conformance has not been formally audited. Automated checks
    (Lighthouse accessibility) pass at 100, which is not the same thing.
  - There is no dark/light theme toggle.
  - "Last update 2024/01/01" predated the company.
